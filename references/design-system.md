# 动态设计系统（默认模板的实现规范）

这份文档是 `templates/scenes.html` 的设计依据，也是你改造模板时的对照表。
所有数值都是默认模板里实际使用的值，改模板请同步改这里。

---

## 一、主题色板

两套主题，改 `:root` 里的 CSS 变量即可整体换肤。默认 editorial 是品牌色。

| 变量 | editorial（默认） | dark | 用途 |
|---|---|---|---|
| `--bg` | `#FAF8F5` 暖象牙 | `#12261E` 深森林 | 画面基底 |
| `--bg-deep` | `#F2EDE4` | `#0C1A14` | 渐变暗端 |
| `--green` | `#1B3A2E` 深森林绿 | `#F2EDE4` | 主文字 / 主结构 |
| `--bronze` | `#C8A35E` 古铜金 | `#C8A35E` | 强调 / 规则线 / 标签 |
| `--wine` | `#5C1A1B` 深酒红 | `#C98A8A` | 标题重点词 |
| `--ink` | `#2C2C2A` 炭灰 | `#F2EDE4` | 正文 |
| `--card` | `#FFFFFF` | `#1B3A2E` | 卡片面 |

三色纪律：**一个画面里绿色系占面积、古铜金只做点缀（≤5% 面积）、深酒红只点标题里的关键词**。超过这个比例就会花。

## 二、字体与排版

| 用途 | 字体栈 | 字号（1080p） | 字重 | 字距 |
|---|---|---|---|---|
| 展示标题 | Georgia, "Songti SC", serif | 6.2vw（约 128px） | 700 | 0.012em |
| 字段标签 | 系统 sans | 1.45vw | 600 | 0.34em 全大写 |
| 正文/说明 | 系统 sans | 1.5~1.7vw | 400 | 默认，行高 1.62~1.72 |
| 数据大字 | Georgia serif | 15vw | 700 | -0.02em，tabular-nums |

规则：
- 标题最多两行，超出就删字，不要缩字号
- 标签一律全大写 + 0.34em 字距，这是「高级感」的最大单一来源
- 数字用 `font-variant-numeric: tabular-nums`，计数动画时宽度不跳

## 三、动效曲线与时长

| 动效 | 曲线 | 时长 |
|---|---|---|
| 入场（位移+淡入+ blur） | `easeOutExpo`：`1 - 2^(-10t)` | 0.9s |
| 词级错峰 reveal | 同上，每词晚 0.09s | 0.62s/词 |
| 出场（与下一镜头交错） | 线性淡出 | 0.35s |
| 数字计数 | `easeOutExpo` | 1.4s |
| 规则线画出 | `scaleX` 0→1 | 跟随入场 |

`easeOutExpo` 与原版 SKILL 里的 `cubic-bezier(0.16, 1, 0.3, 1)` 是同一族——快进慢停，Apple 发布会同款。CSS 里继续用 `cubic-bezier`，JS 驱动时用指数形式（可对任意 t 求值）。

## 四、动量连续性（任何一帧都不静止）

原版公式 `scale = baseScale + t * 0.012` 无界，长镜头下元素会飞出画面。默认模板用**双不可通约频率叠加 + clamp**：

```javascript
const drift  = Math.sin(t * 0.8) * 0.013 + Math.sin(t * 1.37) * 0.008;  // 缩放振荡 ±2.1%
const driftY = clamp(Math.cos(t * 1.2) * 5 + Math.sin(t * 0.93) * 4, -10, 10);  // ±10px
```

为什么叠两个频率：单正弦在极值点瞬时速度为零，逐帧检测会抓到一两帧「几乎静止」的帧（实测 diff 掉到 0.18）。叠一个不可通约分量后合速度永不为零，运动全程连续。

各场景的持续动态：

| 场景 | 持续动态 |
|---|---|
| title | 背景渐变双频游移 + 文字层 0.35 倍反向视差 + 光斑漂移 |
| feature | 产品卡 ±6px 双频浮动 + 极光锥形渐变 200°/s 旋转 |
| metric | 光晕呼吸 `sin(0.9t) + 0.4·sin(1.53t)` + 数字微缩放 |
| outro | 全程 3.5% 缓慢推镜 |

## 五、景深层级

`perspective` 在 2D 截帧流程里意义有限，用**视差权重**替代：

| 层 | 位移权重 | 实现 |
|---|---|---|
| 背景（渐变 + 光斑） | 1.0x | stage transform |
| 内容（文字/卡片） | -0.35x（反向） | `.safe` 的 `--py` |
| 浮动元素（标签/chip） | 1.4x | 独立 transform |

反向位移是制造纵深的关键：同向移动只是「整体在飘」，反向移动才是「有前后」。

## 六、电影质感三件套

1. **胶片噪波**：预渲染 128×128 灰度噪声 PNG（base64 内嵌，避免 SVG feTurbulence 每帧重栅格化——实测那一版单帧 370ms，换位图后归零），`mix-blend-mode: multiply`，透明度 5%（dark 主题 7%）
2. **暗角**：`radial-gradient(115% 88% at 50% 46%, transparent 58%, var(--vignette) 100%)`
3. **交错转场**：镜头首尾各 0.25s，`.cutfade` 用 `--x` 变量在末段淡入底色，与 assemble 的硬切对齐

## 七、性能基线（1920×1080，实测）

| 项 | 成本 | 优化手段 |
|---|---|---|
| `__render(t)` | 2~3ms | 纯 JS 直接写 CSS 变量，不碰布局 |
| 截图（PNG） | ~750ms | 噪波让 PNG 编码爆炸，**默认改用 JPEG q92** |
| 截图（JPEG q92） | ~50ms | 93KB/帧，15 倍提速 |
| 光斑画布 | — | 0.5 分辨率渲染 + CSS 放大，模糊填充量降 4 倍 |

537 帧 @ 4 workers ≈ 25~30s。**成片是 4500kbps H.264，JPEG q92 中间帧对它完全透明**，不需要担心画质损失。

## 八、模板改造契约

1. `window.__render(t)` 必须是纯函数：同样 t 永远画出同一帧，禁止 `Math.random`、禁止读真实时钟
2. 随机元素用种子（`mulberry32`），种子从 URL 参数进
3. 不引用任何网络资源（字体走系统栈，图片走 base64 或本地）
4. 场景类型从 URL 参数 `visual` 取：`title / feature / metric / outro / custom`
5. 尺寸从 `w` / `h` 参数取，竖屏 9:16 时字号用 `clamp()` + `vw` 自适应
