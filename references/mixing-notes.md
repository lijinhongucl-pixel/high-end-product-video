# 混音与母带笔记（audio_engine.py 的实现依据）

## 一、为什么响度归一，而不是峰值归一

两条都归一化到 -1 dBFS 的音轨，听感可以差 10 个 LU。峰值只描述「最大的那个样本」，不描述人耳感受到的响度。网络视频的交付标准是**集成响度**：

| 平台/场景 | 目标集成响度 |
|---|---|
| 网络视频（本工作流默认） | -16 LUFS |
| 播客 | -19 LUFS |
| 电影/影院 | -27 LUFS |
| 广播（EBU R128） | -23 LUFS |

另外两条硬约束：**真峰值 ≤ -1.0 dBTP**（给有损编码留余量，AAC 会抬高峰值），**采样率 48kHz**（视频标准）。

## 二、LUFS 是什么

LUFS = Loudness Units Full Scale，ITU-R BS.1770-4 定义的响度单位，比 dBFS 更接近人耳。计算分三步：

1. **K 加权**：两级滤波器级联
   - 高频搁架：f0 = 1681.97Hz，+4dB，Q = 0.7071（补偿人耳对 2kHz 以上的敏感）
   - RLB 高通：f0 = 38.14Hz，Q = 0.5003（滤除低频，防止轰头内容虚高）
   - 实现用「模拟原型 + 双线性变换」，任意采样率可算；48kHz 下与标准公布系数误差 < 1e-12（tests/test_loudness.py 有对照断言）
2. **分块测量**：400ms 块、75% 重叠（步进 100ms），每块算 K 加权后的均方
3. **门控**：绝对门 -70 LUFS（静音块不计）→ 相对门 = 均值 - 10 LU（小声段不计）

最终 `L = -0.691 + 10·log10(门控后均方均值)`，`-0.691` 是校准常数。

参考标定（本实现实测）：单声道 997Hz 正弦 -20 dBFS → **-23.70 LUFS**；同信号双声道 → -20.69 LUFS。用来自校：如果你的实现对不上这两个数，滤波器系数一定错了。

## 三、真峰值（dBTP）

样本峰值会低估真实峰值：重建后的模拟波形可以冲到两个样本之间。BS.1770 要求 ≥4x 过采样测真峰值。

纯 Python 全量 4x 过采样太慢（8.6M 样本 × 17 抽头 ≈ 数亿次运算）。本实现的裁剪：**只对 |x| ≥ 全局峰值 70% 的局部极大值邻域**做 Blackman 窗 sinc 插值（±16 抽头，核表预计算）。带限信号的插值峰只会出现在样本峰附近，这个裁剪在工程上安全，实测与全量过采样一致。

## 四、限幅器为什么需要「前瞻 + 余量搜索」

直接「超了就压」的限幅器有两个坑：

1. **attack 过冲**：增益降下来需要时间，第一个峰已经冲过去了。解法是把增益施加到**延迟 D = lookahead（5ms）** 的信号上——增益先降到位，峰值才到。
2. **残余过冲**：一阶平滑的增益永远差目标一截，输出仍超上限 0.3~0.9 dB。解法是**余量搜索**：以样本峰值为代理（便宜），每轮把上限再压低 0.5dB，直到样本峰值留出 0.5dB 插值余量；最后用真峰值验收一次。

外层再套响度补偿循环：限幅会轻微拉低响度，最多 4 轮收敛。实测安静素材（需 +2dB 增益）2 轮收敛，突发尖峰素材 margin 1.0dB 后达标。

## 五、侧链闪避的参数

| 参数 | 值 | 理由 |
|---|---|---|
| 人声期间 BGM | 18% | 人声明晰度优先，BGM 只留氛围 |
| 停顿期间 BGM | 35% | 恢复存在感，但不抢 |
| 过渡时长 | 250ms | 约 3 倍时间常数，增益曲线听不出拐点 |
| VAD 阈值 | 帧 RMS 峰值 × 5% | 相对阈值，适配不同录音电平 |

闪避增益曲线由人声总线（铺轨后）的 RMS 包络生成，一阶平滑到目标增益。 syllable 间的能量跌落会让 BGM 轻微呼吸，这是可闻的正常行为，不是 bug。

## 六、BGM 循环缝合

BGM 通常比成片短，需要循环。直接循环会在接缝处爆音。实现：把 BGM 尾部 5ms 交叉淡化折进头部，接缝处首尾样本连续，听不出环点。

## 七、AAC 编码的响度漂移

AAC 有损编码通常让集成响度掉 0.1~0.3 LU、真峰值略微抬高。`assemble_video.py --verify` 会把成片音轨解码回 WAV 复测，±1 LU 容差内算达标。**不要跳过这步**：它抓的是「母带明明达标、成片却漂了」的静默失败。
